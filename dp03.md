# 416. Partition Equal Subset Sum
```java
class Solution {
    public boolean canPartition(int[] nums) {
        // Step 1: Calculate the total sum of the array
        // Because the problem asks if we can partition the array into two subsets
        // such that both subsets have the same sum.
        int sum = 0;
        for (int num : nums) sum += num;

        // Step 2: If the total sum is odd, it’s impossible to divide it evenly.
        // Example: if sum = 7, you can’t split it into two equal integers.
        if ((sum & 1) == 1) return false;

        // Step 3: Our target subset sum is half of the total sum.
        // We need to check if there's a subset of nums that sums up to this target.
        int target = sum / 2;

        // Step 4: Define a DP array where dp[s] means:
        // "Is it possible to form a subset with sum s?"
        // We initialize it with false by default.
        boolean[] dp = new boolean[target + 1];

        // Step 5: Base case — we can always form a sum of 0 by choosing no elements.
        dp[0] = true;

        // Step 6: Iterate over each number in the array.
        // For each number, we’ll update the dp array to include possible new subset sums.
        for (int num : nums) {
            // We iterate backwards from target → num to avoid reusing the same element twice.
            // (If we iterate forward, we might count one element multiple times.)
            for (int s = target; s >= num; s--) {
                // dp[s] becomes true if:
                // 1) It was already true before, OR
                // 2) We can form sum (s - num) and add this num to reach s.
                dp[s] = dp[s] || dp[s - num];
            }

            // Optimization: If we already found a subset with sum == target,
            // we can immediately return true without further processing.
            if (dp[target]) return true;
        }

        // Step 7: Return whether it’s possible to reach the target subset sum.
        return dp[target];
    }
}
```
